## Спринт 2. Практическое задание

## Как запустить

Запускаем контейнер из папки **sharding-repl-cache**

```shell
docker compose up -d
```

Запускаем скрипт из папки **sharding-repl-cache**

```shell
./scripts/mongo-init.sh
```

Смотрим статус выполнения и ждем заполнения базы данными, в конце выполнения выполняется проверка на количество документов в каждом из шардов, и статус реплик

Увидеть настройки финальной реализации MongoDB можно по эндпоинту [http://localhost:8080/](http://localhost:8080)
______
Для проверки кэширования запустить скрипт **redis.sh** из папки sharding-repl-cache/scripts, который так же выведет информацию о статусе использования кэша Redis в формате Json
